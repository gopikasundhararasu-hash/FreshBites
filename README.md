# 🍔 FreshBite – Online Food Ordering Website

FreshBite is a simple and user-friendly online food ordering website developed using HTML, CSS, and JavaScript.

## 📌 Project Overview

FreshBite allows users to browse food items, search for dishes, add items to a cart, and place an order by entering their delivery details.

## ✨ Features

- 🏠 Home page
- 🍕 Food menu
- 🔍 Search food items
- 🛒 Add to Cart
- 💰 Display food prices
- 📦 Order placement
- 📍 Delivery address input
- 📱 Phone number input
- 🖼️ Food images
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
